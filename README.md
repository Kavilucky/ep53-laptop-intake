# Экспресс-диагностика корпоративных ноутбуков при скупке: n8n, PostgreSQL, Ollama и Telegram (Docker Compose, Cloudflare Tunnel)

Набор к ролику «Диагностика ноутбуков при скупке». Загрузочная флешка снимает телеметрию (износ батареи, состояние SSD, серийники платы и системы, признаки корпоративной привязки MDM и Windows Autopilot) и шлёт на ваш n8n через Cloudflare Tunnel. PostgreSQL сверяет серийники со стоп-листом, код принимает решение (запрет, ручная проверка или лимит цены), локальная Ollama добавляет ограниченную уценку, Telegram-бот присылает карточку. Без абонентской платы за сервис: платите за сервер.

**Набор только выявляет признаки корпоративной привязки и помогает отказаться от сделки. Он не снимает и не обходит блокировки.**

## Что внутри
| Файл | Для чего |
|---|---|
| `docker-compose.yml` | PostgreSQL 16, Ollama, n8n, cloudflared (Cloudflare Tunnel); тома `pg_data`, `n8n_data`, `ollama_data`, `backups` |
| `.env.example` | пример настроек: пароль базы, ключ шифрования n8n, домен, токен туннеля, чат приёмки, токен приёмки `INTAKE_TOKEN`, модель Ollama |
| `init.sql` | таблицы `stop_list`, `price_rules`, `devices` (журнал приёмок с вердиктом `allow`, `review` или `forbidden` и причинами) |
| `laptop_intake_n8n.json` | сценарий n8n на 21 узел: вебхук приёмки, проверка токена, сверка со стоп-листом и ценой, решение, расчёт Ollama, журнал, карточка в Telegram, ответ скрипту, ночная выгрузка; идентификаторы подключений пустые |
| `collect_telemetry.py` | скрипт для живой Linux-системы на флешке (только чтение): батарея, SSD по SMART, серийники, признаки прошивки, офлайн-следы MDM и Autopilot |
| `backup.sh` | резервная копия базы оценок: дамп PostgreSQL и архив настроек (правило 3-2-1) |
| `Инструкция.txt` | пошаговый запуск и честные ограничения |

## Быстрый старт
1. VPS с Linux, Docker и Docker Compose; бот у @BotFather; туннель Cloudflare Zero Trust (маршрут на `http://n8n:5678`).
2. `cp .env.example .env`, значения сгенерируйте `openssl rand -hex 32` (пароль базы, ключ n8n, токен приёмки), впишите домен и токен туннеля.
3. `docker compose up -d`, затем `docker compose exec ollama ollama pull <модель из OLLAMA_MODEL>`; создайте администратора n8n.
4. Заполните `price_rules` и `stop_list`, импортируйте `laptop_intake_n8n.json`, создайте учётные данные Telegram и PostgreSQL, активируйте сценарий.
5. На флешке с живой Linux-системой запустите `sudo python3 collect_telemetry.py --sticker СЕРИЙНИК_С_НАКЛЕЙКИ --dry-run`, затем с `--url` и `--token`.

Аренда VPS: [Timeweb Cloud](https://timeweb.cloud/r/nf413716) (партнёрская ссылка, автор получает вознаграждение; условия на сайте, проверяйте актуальные).

## Честные ограничения
- Автор стек, сценарий, SQL-схему и скрипт на живом сервере и на реальных ноутбуках **не запускал**. Логика узлов Code проверена в Node, сбор батареи, SSD и серийников в скрипте проверен в Python на подставных данных; поиск следов в офлайн-реестре Windows (`hivexregedit`) не проверялся. Теги образов (`latest`), узлы и имена параметров сверьте с документацией ваших версий.
- Если системный раздел Windows стёрт, офлайн-признаки не проверены: ноутбук получает «ручную проверку», а не «чисто». Не покрыты пароли BIOS и UEFI, персистентные модули вроде Absolute и облачные привязки без следов на диске. У продавца запрашивайте подтверждение снятия с MDM.
- Серийник с наклейки сравнивается с серийником системы, прошитым в плату (SMBIOS). У разных производителей серийники устроены по-разному: проверьте правило сверки на своих моделях.
- Базовые цены и коэффициенты износа в примере условные. Ollama добавляет только 0-15% уценки поверх формулы, качество расчёта не проверялось; решение о цене за человеком.
- Вебхук открыт наружу через Cloudflare Tunnel: токен `X-Radar-Token` и очистка данных есть, ограничения числа запросов нет, добавьте правила Cloudflare. Условия бесплатного Cloudflare Tunnel проверяйте на сайте Cloudflare.
- Законность выкупа и происхождение техники, согласие продавца на диагностику, персональные данные на накопителях (152-ФЗ): проверьте у юриста. Это не юридическая консультация.
- Убыток 145 000 ₽, время теста 5 секунд, цены и проценты износа в ролике иллюстративные параметры и оценки владельца.
- Нужен бэкап базы оценок по правилу 3-2-1: 3 копии, 2 носителя, 1 вне сервера; не удаляйте оригиналы, пока восстановление не проверено.
